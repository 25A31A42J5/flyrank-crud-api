# FlyRank AI - CRUD API

A beginner-friendly REST API built with Python and FastAPI
to manage tasks using CRUD operations.

## Features

- Create new tasks
- Retrieve all tasks
- Retrieve a task by ID
- Update existing tasks
- Delete tasks
- Health-check endpoint
- Automatic API documentation with Swagger UI
- Error handling for tasks that do not exist

## Technologies Used

- Python
- FastAPI
- Pydantic
- Uvicorn
- Git and GitHub
